# Render deployment

## Publish

1. Open [Deploy to Render](https://render.com/deploy?repo=https://github.com/dorsabag/Roymosherip), sign into your Render account, and authorize access to this GitHub repository.
2. Review the Blueprint's web service and database plans and region. These are paid services; Render shows the price. Create the Blueprint only after reviewing the cost. Use the same region for both resources.
3. Render runs the pinned pnpm frozen-lockfile build, applies checked-in migrations in its pre-deploy step, and starts the combined website/API service. `DATABASE_URL` is bound to the managed database, `SESSION_SECRET` is generated by Render, and `PORT` is supplied by Render. Build steps contain no production database mutations. Server startup contains no schema changes or data seeding.
4. Wait for the web service to become healthy and open the HTTPS URL assigned by Render. Verify the public page, `/admin`, and `/api/healthz` (JSON with `status: ok`). Unknown `/api` routes return 404, not the frontend document.

## Set up family administrator access

Administration is deliberately disabled until `ADMIN_PASSWORD_HASH` is set; there is no default password.

1. Visit `/admin-password.html` on your new HTTPS site. This standalone setup tool is not linked from the memorial. It creates a bcrypt hash entirely in your browser and makes no network requests. Choose a unique password and retain it in a password manager.
2. Copy the resulting hash into the Render web service's Environment settings as `ADMIN_PASSWORD_HASH`. Save/redeploy. Never enter the plaintext password into that variable, chat, source code, or logs.
3. Open `/admin` and sign in with the original password. Verify the pending/approved/rejected tabs using a clearly identified test submission. Remove that test record when finished.

The helper page is publicly reachable but cannot change server configuration or grant administrator access. Its input stays within your browser. Only someone with access to the Render environment settings can install a hash.
