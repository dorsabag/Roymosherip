# Roy Moshe Memorial

Hebrew RTL memorial website preserving family-supplied stories, images, music, and tributes. Visitor memories are stored in PostgreSQL and published only after family moderation.

The owner's preferred destination is the Sites hosting used for their existing `dorsabag.chatgpt.site` projects. Continue with [the Sites deployment handoff](docs/sites-handoff.md). Publishing requires a task with Sites tools available; the cloud-onboarding task cannot publish to Sites or enable those tools.

The supplied [PRD](docs/product-requirements.html), application source, optimized public media, and original image assets are included in this repository. No re-upload is needed to continue.

Render configuration remains as an optional alternative, not a required service. Nothing has been deployed to Render. See [alternative deployment instructions](docs/render-deployment.md) only if the owner chooses that route.

The original Replit site remains separate. Uploading source/media does not transfer its visitor-memory database or administrator credentials.

Development setup and validation history: [migration status](docs/migration-status.md).
