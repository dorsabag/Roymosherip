# Roy Moshe Memorial

Hebrew RTL memorial website preserving family-supplied stories, images, music, and tributes. Visitor memories are stored in PostgreSQL and published only after family moderation.

[Deploy to Render](https://render.com/deploy?repo=https://github.com/dorsabag/Roymosherip)

The Render Blueprint creates one Node.js web service and a managed PostgreSQL database. It uses paid `starter` web and `basic-256mb` database plans; Render shows current pricing before creation. See [deployment instructions](docs/render-deployment.md).

The original Replit site remains separate. Uploading source/media does not transfer its visitor-memory database or administrator credentials.

Development setup and validation history: [migration status](docs/migration-status.md).
